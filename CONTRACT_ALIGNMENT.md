# Contract Alignment

This repository is a **portfolio presentation and review surface**. It owns no authority semantics and must not become an alternate implementation.

The canonical semantic contract is maintained only in [`cranium-kernel`](https://github.com/worthwyl2022-cloud/cranium-kernel). Portfolio case studies must identify source repository, commit/version, exact verification command, result, evidence label, and residual limitation. Screenshots, narrative claims, static reports, and generated receipts are presentation material—not execution proof.

Acquisition-facing language must preserve the distinction between a real Kernel-backed result and a fixture, test-only result, design, or unverified claim.
