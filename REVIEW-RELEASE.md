# Public review release

**Review package:** `cranium-public-review-v1.0.0`

This is a frozen public review entry point for the Cranium Ecosystem. It provides a deterministic ten-minute proof and architecture visual while keeping proprietary implementation repositories private for controlled diligence.

## Verify

```bash
bash public-review/run-proof.sh
```

Expected result:

```text
PASS: bounded transition, stale-input rejection, and receipt integrity verified
```

Review the package at [`public-review/`](./public-review/) and the architecture visual at [`public-review/cranium-architecture.svg`](./public-review/cranium-architecture.svg).

This package is engineering evidence only. It is not independent security certification, a production performance claim, or a substitute for the private diligence package.
